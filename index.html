Simulasi Visual Interaktif Struktur Data

Eksperimen langsung dengan menambahkan, menghapus, dan memeriksa alur data secara visual dan real-time.

Model 1

List (Array Dinamis Berindeks)

Mendukung akses bebas acak (Random Access) via nomor indeks.

Base RAM: 0x100 | Step: 4 Bytes
Ketik nilai dan klik tombol aksi di atas untuk melihat respon alur list.
Model 2

Stack (Tumpukan - Disiplin LIFO)

Last In, First Out — Satu-satunya pintu keluar-masuk adalah puncak (Top).

Top: NULL
Status: Siap menumpuk data. Kapasitas maksimum 6 elemen.
✨ Tantangan HOTS: Parentheses Validator

Validasi Pasangan Tanda Kurung

Compiler memanfaatkan prinsip Stack LIFO untuk menguji apakah seluruh kurung ( ), [ ], dan { } memiliki pasangan seimbang.

Hasil validasi per karakter akan ditampilkan di sini.
💡 Tips: Coba hapus salah satu kurung tutup dan perhatikan pesan galatnya!
Model 3

Queue (Antrean - Disiplin FIFO)

First In, First Out — Masuk dari ujung REAR (belakang), keluar dari FRONT (depan).

FRONT (Keluar) ➔➔➔ REAR (Masuk)
⬅️ Arah Keluar (FRONT / Head) Arah Masuk (REAR / Tail) ⬅️
Status antrean siap. Masukkan data ke antrean untuk mempraktikkan keadilan FIFO.
